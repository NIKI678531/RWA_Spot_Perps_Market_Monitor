# 基线按 market_session 分层，统计量用中位数 + MAD

RWA 代币 24/7 交易，但它们代表的证券不是。周末与美股盘中的成交量结构差异是数量级的，
盘前盘后与盘中的差异同样显著。若用单一混合基线，每个周一开盘都会批量误报，
系统三天内就会被当成噪音关掉。

决定：基线以 `(entity_id, metric, market_session)` 三元组为键，
`market_session ∈ {RTH, PRE, AH, CLOSED_WEEKDAY, CLOSED_WEEKEND, CLOSED_HOLIDAY}`；
统计量用中位数与 MAD，`robust_z = 0.6745 × (x − median) / mad`；
同 session 历史不足 14 个快照时只记录不告警。

## Considered Options

- **按自然日二分（工作日 / 周末）。** 这是早期设计。被否：它把盘中与盘后混在一起，
  而这两者的差异与工作日 / 周末的差异同量级。
- **均值 + 标准差。** 被否：分布极度右偏——基线数据集中 Top-10 合约占 Binance TradFi 成交 78.2%，
  单一合约（SPCX）占 28.2%。均值会吸收掉它本应检测的那个尖峰。
- **按标的所在市场的交易日历分层（含非美市场）。** 暂缓：韩国、港股标的目前占比低，
  引入多市场日历的复杂度大于收益。`market_session` 目前以美股日历为准，此限制记在架构文档已知边界中。

## Consequences

- 分层意味着每个实体需要维护 6 条基线序列而非 1 条，达到可告警状态所需的日历时间更长。
- MAD 为 0（长期静默的标的）时 `robust_z` 返回 `inf`。这是诚实的答案：
  相对于一条平坦基线的偏离在 MAD 单位下无界。绝对量门槛负责阻止它单独触发告警。
