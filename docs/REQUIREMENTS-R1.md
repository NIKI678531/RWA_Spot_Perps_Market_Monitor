## 2. 端到端验收场景

### 场景 A · 沉寂 Pre-IPO 突然放量

- **给定** 同一底层已有 ≥14 个同 session 历史快照，且历史中位数接近沉寂。
- **当** Adjusted 绝对量超过约 $50k、超过 MAD 阈值、连续 2 次确认，且数据可验证。
- **则** 首页 Q2 显示 high/critical 机会，异常详情完整展示 evidence，点击进入 Underlying 360；
  owner 可认领、创建研究任务，并在复盘记录最终结论。

### 场景 B · Raw 很高但 Adjusted 接近零

- **给定** 来源报告高成交，但主要 pair 被标记 `anomaly` / `stale`。
- **则** Raw 与 Adjusted 并列，业务排序使用 Adjusted，页面明确质量原因；
  **不得**进入首页机会、主动通知或发行候选；数据质量页产生一条可处理缺口。

### 场景 C · 发行商 / 场所份额迁移

- **给定** 同一 metric scope 内某 issuer / venue 份额持续迁移，且分母合法。
- **则** 专题页显示变化、贡献底层与跨所证据，`RATIO` 使用明确权重；
  达到异常门时可分派给渠道/合作 owner，且**不把份额与金额相加**。

### 场景 D · 新产品 1h/6h/24h 真实需求

- **给定** 新包装或合约上线并登记 open 时间。
- **则** 系统按窗口保存不可变快照，展示成交、OI、跨所与质量证据；
  24h 后只有通过绝对量、持续性、量-OI 协同、跨所、质量与映射门的产品进入候选，其余给出降级理由；
  候选仍须经过客户、合规、对冲、做市与委员会评估，**不得由分数直接批准**。

## 3. R1 发布退出标准

- 四个验收场景全部通过，且每个流程可从 首页 → 告警 → Underlying 360 → owner 处理 → 复盘 走通。
- 任何管理层可见告警的 evidence 完整率为 100%；`Not verified` 与 0 无混淆样本。
- 全站不存在跨 metric scope 合计或 `RATIO` 求和；自动化契约测试通过。
- Morning / Afternoon 冻结版连续 5 个工作日按时生成且不可变；修订链测试通过。
- 角色与分享脱敏测试通过；关键页面键盘与可访问性验收通过。
- 生产形态不依赖 PVC；报告在容器重启后仍可访问。

## 4. 成功指标

上线后按周追踪，首月建立基线。这些指标衡量的是**决策闭环是否在转**，不是页面浏览量。

| 指标 | 定义 | R1 目标 |
|:--|:--|:--|
| 已确认有效需求信号 | 被 owner 判定为真实需求且证据完整的告警数 | 首月建立基线 |
| 信号 → 研究任务转化率 | 创建研究任务的有效信号 / 已确认有效信号 | 可按主题、owner、严重度分解 |
| 高/严重告警误报率 | 标记误报的高/严重告警 / 已完成复核的高/严重告警 | 首月校准；≤25%，后续逐季下调 |
| 检测领先时间 | 系统首次合格告警至人工首次记录同一机会的时间差 | 可观测并复盘，R1 不设硬承诺 |
| 证据完整率 | 已发布告警中 evidence 字段完整的比例 | **100%** |
| 处理及时性 | 高/严重告警在 1 个工作日内被认领或给出不处理原因 | ≥90% |
| 影响决策数 | 被产品/合作/发行评估引用的信号数 | 月度报告列明案例与结论 |
| 管理层可读性 | 目标用户 30 秒内正确复述 Top 变化与所需动作 | 可用性测试通过率 ≥80% |

## 5. 非功能要求

| 类别 | 要求 | 验收方式 |
|:--|:--|:--|
| 性能 | 首屏骨架 ≤1s；缓存命中下核心数据 ≤3s；图表交互 ≤200ms | 前端性能测试与真实数据压测 |
| 可靠性 | 局部源失败不拖垮整页；任务幂等；冻结版可重建 | 故障注入与恢复演练 |
| 可追溯 | 快照、告警、处理、导出、edition 全部有版本和审计 | 随机抽样端到端回溯 |
| 安全 | 认证、角色授权、分享脱敏、审计日志 | 权限矩阵测试 |
| 可访问性 | WCAG AA、键盘、`focus-visible`、数据表替代 | 自动扫描 + 手工键盘测试 |
| 可观测性 | 采集、API、调度、报告、对象存储均有状态和告警 | 监控面板与演练 |
| 部署 | 后端无 PVC 依赖；报告写 TOS/DB；容器内无持久化文件 | K8s / compose 验证 |
| 国际化 | R1 中文主界面，保留中英韩/繁中机制；术语一致 | 关键页面文案抽检 |
