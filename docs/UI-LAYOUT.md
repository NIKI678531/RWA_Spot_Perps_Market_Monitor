# 版式与信息架构

> `DESIGN.md` 是权威视觉规范，**本文件不修改它**。本文只规定这个产品的版式落地方式。
> 图表规范见 `DATAVIZ.md`。

## 1. 全局壳

```
┌───────────────────────────────────────────────────────────────────┐
│ ░ 液态背景层 (z:0, pointer-events:none) + background-overlay ░     │
│ ┌────┬──────────────────────────────────────────────────────────┐ │
│ │    │  顶栏 56px：面包屑 ·│· 数据时间戳 · 语言 · 明暗切换        │ │
│ │ 图 ├──────────────────────────────────────────────────────────┤ │
│ │ 标 │                                                          │ │
│ │ 侧 │      内容区   max-width 1440   padding 32 / 40           │ │
│ │ 栏 │                                                          │ │
│ │ 72 │                                                          │ │
│ └────┴──────────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────────┘
```

- **左侧 rail 72px**，图标 + hover 展开为 200px 浮层（不推挤内容）。
  常驻侧栏会吃掉宽表与时序图最需要的横向空间。
- **分组用间距不用分割线**（`DESIGN.md` 原则 2 留白优先）：组间 `spacing.lg` (24px)，组内 `spacing.sm` (8px)。
- **顶栏必须常驻数据时间戳**。看监控的人随时需要知道数据有多新；
  时间戳缺失时整个界面的数字都不可信。
- 激活态用**左侧 3px 渐变竖条**，不用整块底色（`DESIGN.md` Shapes 节：高光用描边不用填充）。

## 2. 四个版式模板

10 个页面全部套用其中之一。每页各写各的排版必然导致不一致。

### T1 概览 — Overview

`DESIGN.md` 原则 7「首屏叙事」的落地：**第一屏不放任何图表**。
敢留白是高级感的来源；打开就看到一句人话结论，比看到一堵数字墙更快建立信任。

```
            ░ 液态背景 + background-overlay ░

        下午好，{name}                                display-hero 36px
        今天 RWA 现货 $2.62bn (+3.1%)，永续 $4.44bn，
        3 条待处理告警。                               body-lg / text-secondary

        ┌──────────────────────────────────────┐ (⊕)  input 720px 居中
        │  搜索标的 / 发行商 / 交易所…          │       + button-send
        └──────────────────────────────────────┘
        (今日告警 3) (热度榜) (永续vs现货) (周报)      入口 chip
                        ⌄ 向下看数据                   button-scroll
━━━━━━━━━━━━━━━━━━━━━ 一屏折叠线 ━━━━━━━━━━━━━━━━━━━━━
        ┌───────┬───────┬───────╎───────┬───────┐    KPI 带
        │现货市值│现货成交│DEX流动│永续成交│永续 OI│    ╎ = 口径分隔
        └───────┴───────┴───────╎───────┴───────┘    (虚线：不可加总)
        ┌────────────────────────┬─────────────┐
        │  异常告警流    (2fr)    │ 热度 Top10  │
        │  卡片 + 左侧 3px 色条   │   (1fr)     │
        └────────────────────────┴─────────────┘
```

- Hero 的「一句话」由 `/api/kpi/executive` 生成，含未验证项时降级为
  「今天有 2 项指标未能验证」，**不省略、不填 0**。
- KPI 带按 STOCK / FLOW 分组，组间插入 `spacing.lg` 的空隙与一条虚线，
  **视觉上就不成立的加法，代码里也加不了**。
- 折叠线以下的内容随滚动 stagger 入场（`60ms × i`，上限 600ms）。

### T2 榜单 — Spot Scale · Venues · Issuers · Perps · Themes

```
┌─────────────────────────────────────────────────────┐
│ 页面标题 h1        │  筛选条 chip 组（tier/时间/口径）│
├─────────────────────────────────────────────────────┤
│                                                     │
│          主图（Hero，高度 360px）                    │
│          横向条形或双轴折线                          │
│                                                     │
```

- 一屏一焦点的焦点是**主图**（`DESIGN.md` 原则 1 明确允许主图表作为 Hero）。

- 表格 raw / adjusted **必须同屏并排**，不得用 tab 切换——tab 会让人只看到其中一个。

**按口径分栏是硬约束的版式化**：不同 `MetricScope` 物理上分在不同的卡片容器里，
中间有明确的分隔与各自的标题。跨口径相加在版面上就不成立，比在代码里抛异常早一步。

### T4 流水 — Anomaly Radar · Data Quality

```
┌──────────────────────────────┬──────────────────────┐
│ 筛选：severity / family /     │                      │
│       detector / 时间         │   证据抽屉           │
├──────────────────────────────┤   （选中时滑入）      │
│ ○─ 09:00  CRITICAL           │                      │
│ │  SPCXB 沉睡唤醒 T2         │   原始值   $362,076  │
│ │  bStocks · Pre-IPO         │   基线中位 $812      │
│ ○─ 08:15  HIGH               │   robust_z 41.2      │
│ │  LBank 份额 -6.2pp  T6     │   样本量   14        │
│ ○─ 07:00  MEDIUM             │   session  周末闭市  │
│ │  ...                       │   规则     ...       │
└──────────────────────────────┴──────────────────────┘
```

- 时间轴按天分段，同 `(entity, detector)` 的重复出现折叠为一条并显示 `occurrence_count`。
- 抽屉宽 420px，从右滑入（`dur-base` + `ease-emphasized`）。
- **证据字段一个都不能省**：原始值、基线、`robust_z`、样本量、`market_session`、规则名。
  抽屉的存在就是为了让「为什么报这个」有答案。
- 横截面族告警的抽屉显示的是**对照组**而非基线（组名、组内中位数、组内样本数）。

## 4. 状态

每个数据区域必须实现四态，缺一不可：

| 态 | 表现 |
|:--|:--|
| 加载 | 骨架屏 + shimmer，形状要暗示即将出现的版式。**禁止 spinner** |
| 有数据 | 正常渲染 |
| 空 | 图标 + 一句说明 + 一个可执行动作。不显示空白卡片 |
| 未验证 | 灰色斜纹占位 + 「未验证」标签 + 最后一次成功采集的时间。**绝不显示 0** |

「空」与「未验证」是两个不同的态，不得合并：
空是「观测到了，确实没有」，未验证是「没能观测到」。

## 5. 响应式

断点沿用 `DESIGN.md`：`768 / 1024 / 1440`。

| 断点 | 变化 |
|:--|:--|
| ≥1440 | 完整版式，内容区居中，最大宽 1440 |
| 1024–1440 | T1 双栏变 3fr/2fr；T3 双口径栏保持并排 |
| 768–1024 | rail 收为顶部抽屉；T3 双口径栏上下堆叠，**分隔与口径标题必须保留** |
| <768 | 表格转卡片列表；主图高度降至 240px；KPI 带横向滚动，**口径分隔线随之滚动** |

任何断点下，口径分组的视觉分隔都不得被折叠掉——这是版式承担的正确性职责，不是装饰。

## 6. i18n

所有用户可见文案走 `t(key, '中文 fallback')`，zh / en / ko / zh-TW 四语种齐备（`DESIGN.md` Do's）。

数字格式随语言切换，但**金额缩写单位保持 K / M / B 不本地化**——
中文语境下的「亿」与英文 `B` 换算关系不同，混用会直接产生读数错误。
